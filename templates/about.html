About PredictMedix

An Explainable Machine Learning framework for medical cost prediction.

Project Overview

Rising healthcare expenses make accurate medical cost prediction important for both individuals and insurance providers. PredictMedix applies data-driven machine learning models to estimate medical insurance charges using structured lifestyle and demographic datasets.

By feeding lifestyle features like Age, BMI, and Smoking status into trained regression models, the platform predicts the expected charges instantly.

Regression Models Implemented

  • Linear Regression (Baseline)
  • Decision Tree Regressor
  • Random Forest Regressor (High Performance)
  • Gradient Boosting / XGBoost Regressor
  • Support Vector Regression (SVR)

Technology Stack

The framework is built using modern libraries in the Python machine learning ecosystem:

Python 3 Flask (Web Framework) XGBoost & Scikit-Learn SHAP (Explainable AI) MongoDB (User Auth) xhtml2pdf (Report Export) Pandas & NumPy
